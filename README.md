# LingCraft · 全能创作工具

自媒体全能创作工具，一站式支持今日头条文章采集、AI 智能创作、爆款二创改写与视频混剪成片。

## 核心功能

- **文章采集**：采集今日头条作者文章（标题/正文/阅读量/点赞/评论），配图自动下载并智能去水印
- **AI 原创创作**：基于联网真实素材生成原创爆款文章，支持多平台文风（头条/公众号/知乎/小红书等）
- **爆款二创改写**：自动联网补充素材 + 原创度三条硬线（增量案例/结构重组/独立观点），显著降低判搬运风险，支持采集原图自动插入排版
- **视频创作**：文案生成 → 配音（多种音色）→ 素材混剪 → 字幕 → BGM → 一键成片；支持标题样式/显示时长、6 种转场特效、生成中随时取消
- **批量创作**：热搜榜/文章库自由勾选，一键批量生成并自动存档
- **多格式导出**：Word、Excel、ZIP 打包，图文排版优雅；软件内点击「？」随时查看内置使用说明
