# LingCraft & LingCraft · 全能创作工具 (Toutiao Scraper Studio Pro)

> 基于 **Playwright / Patchright 隐蔽内核 + FastAPI + 现代化 Glassmorphic Web UI + 大模型自媒体创作引擎** 构建的今日头条作者文章全自动采集、全网实时热点追踪、AI 爆款二创改写、Word 图文排版与数据分析系统。

---

## 🌟 核心功能板块

### 1. 👤 作者文章批量采集 (主力引擎)
- **作者链接自定义**：支持填入任意今日头条作者主页。
- **全参数控制**：抓取篇数限制 (`--max-articles`)、正文 Markdown 提取开关 (`--fetch-content`)、高清配图批量下载 (`--download-images`)、请求延时调节 (`--delay`)。
- **毫秒级进度流 (SSE)**：动态展示当前滚动批次、正文提取进度与实时耗时。
- **流式终端日志**：实时输出网络请求、解析动作与防封状态。
- **文章数据看板**：按阅读量/点赞数/评论数/发布时间多维排序与关键词即时检索。
- **多格式导出交付**：Excel 汇总表 (`.xlsx`)、CSV 表格 (`.csv`)、Word 带图排版 (`.docx`)、完整 JSON (`.json`)、全量 ZIP 压缩包 (`.zip`)。

### 2. 🔥 全网实时热点雷达 (官方 Top 50 热搜榜)
- **官方实时直连**：实时获取今日头条官方 PC 端热搜榜 50 强。
- **热点全字段**：排名徽章、热搜标题、热搜热度值、爆/热/新/荐标签。
- **一键选题应用**：点击直接在今日头条中打开该热点，或一键复制标题作为 AI 写作选题。

### 3. ✍️ 自媒体 AI 智能创作与爆款拆解
- **多模型兼容**：支持 DeepSeek、阶跃星辰、通义千问、OpenAI、SiliconFlow 等所有兼容 OpenAI 规范的模型。
- **爆款拆解与评分**：自动计算文章互动热度指数，提炼黄金开头 (Golden Hook) 与情绪触发词（冲突/悬念/共情/利他）。
- **原创二创生成**：支持流式生成爆款开头、段落扩写、风格仿写与文章精修。

### 4. 🔐 离线非对称加密会员系统 (Ed25519)
- **零破解风险**：采用 Ed25519 椭圆曲线数字签名，客户端仅保留公钥，私钥严格保存在开发者发码工具中。
- **硬件机器码绑定**：自动读取 Windows 原生硬件特征（CPU/主板/BIOS/UUID）生成 12 位唯一机器码。
- **独立发码工具**：内置 `license_tool/` 独立发码器，支持周卡/月卡/季卡/年卡/永久终身授权。

## 🚀 快速启动

### 方式一：双击一键启动 (推荐)
直接双击运行根目录下的：
```text
run_app.bat
```
程序将自动启动后台服务并在默认浏览器中打开控制台 (`http://127.0.0.1:8765/`)。

### 方式二：命令行启动 Web 调试
```bash
python server.py
```

### 方式三：启动桌面原生客户端
```bash
python desktop_app.py
```

## 👑 开发者发码指南

发码工具位于 `license_tool/` 目录：

1. **获取客户机器码**：客户在软件界面点击顶部【会员激活】，复制其 12 位机器码（例如 `F88A-2CFE-EE53`）。
2. **一键签发激活码**：
   - 双击运行 `license_tool/双击签发激活码.bat`。
   - 粘贴客户机器码，选择授权方案（1.周卡 / 2.月卡 / 3.季卡 / 4.年卡 / 5.永久终身 VIP / 6.自定义天数）。
   - 回车即可生成形如 `TTS1.eyJle...` 的激活码密文，并自动追加记录到 `issued_licenses.txt`。
3. **客户激活**：客户将激活码粘贴到软件激活弹窗中，点击“立即验证并激活”，即可秒级解锁 VIP 特权！
