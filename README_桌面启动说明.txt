【快捷启动方式】
1. 双击运行【启动桌面客户端.vbs】:
   - 以独立 Windows 桌面原生窗口运行（Microsoft Edge WebView2 渲染内核，无任何黑框命令行）。
2. 双击运行【run_app.bat】:
   - 启动本地服务并自动在默认浏览器中打开。

--------------------------------------------------------------------------------
【发布与发码工具】
1. 客户单文件安装包:
   - 路径: release\ToutiaoStudio_Setup_v2.5.0.exe
   - 作用: 单文件安装包向导，发给客户直接双击安装。

2. 绿色免安装版主程序:
   - 路径: dist\ToutiaoStudio\ToutiaoStudio.exe

3. 开发者发码工具 (仅你个人持有):
   - 路径: license_tool\双击签发激活码.bat
   - 作用: 输入客户机器码，签发 7天体验卡 / 30天月卡 / 永久 VIP 激活码。

4. 重新打包构建工具:
   - 双击运行【一键打包桌面客户端.bat】
